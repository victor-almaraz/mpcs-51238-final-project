# Templates

The projects New Project starts from: each folder is copied whole to the new project's folder, which then opens. Each plays `main.lisp`.

## empty-piece

A piece that builds nothing yet: a module and its `main` piece, to fill in.

## sine-tone

A sine tone of 440 Hz at -18 dB on both channels, the smallest piece that sounds.

## midi-instrument

A subtractive synthesizer of eight voices for any MIDI keyboard, through a reverb, on both channels.
