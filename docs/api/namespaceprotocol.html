◆ oscRules

enum class protocol::oscRules : std::uint8_t
strong

The rules a packet is decoded by.

Enumerator
control 

The client and server's own messages (protocol.md §2.1, §2.2): the type tags i h f d s b, padding of zeros, and nothing after the last argument.

lenient 

Messages from other programs, such as those a piece sends to a page (protocol.md §2.5, io.md §12.5): every type tag of OSC 1.1; a message without a type tag string has no arguments, padding is skipped unread, and bytes after the last argument are ignored.
