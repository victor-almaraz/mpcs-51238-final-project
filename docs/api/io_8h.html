Detailed Description

Queues between sources and sinks and the I/O layer (primitives.md §1.2, §7.2, §7.3). Primitives never touch devices or sockets. A source owns an input port that an I/O thread fills; a sink owns an output port that an I/O thread drains. The hub tracks the ports so the I/O layer can find them.
