Detailed Description

Control pipe: one value per channel.

A write replaces the value, which holds until the next write (§5.3). Values are atomics so other threads can read them (/c.get).

Sets the channel count and feedback flag.

Channels that become active take channel 0's value, which a reader of the narrower pipe saw on every channel; a feedback change carries the current values into both halves, so the next block end publishes no stale value.
