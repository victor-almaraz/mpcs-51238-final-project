static std::vector< std::filesystem::path > tui::fileStore::listProject ( const std::filesystem::path & root)
static

Lists regular files under root, sorted, relative to it.

Hidden entries (names starting with .) and build directories are skipped. Symbolic links are listed by their own names, and linked directories are descended into, except a link to a directory that contains it, which would repeat forever.

static std::optional< std::string > tui::fileStore::writeAtomic ( const std::filesystem::path & path,
const std::string & text )
static

Writes text to a temporary file in the target's directory, flushes it, and renames it over path.

When path is a symbolic link, the file it names is replaced and the link is kept. On failure the original file is unchanged and the returned message describes the error (tui.md §7.2).
