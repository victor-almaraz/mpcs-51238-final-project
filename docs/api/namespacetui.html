Detailed Description

The terminal editor: buffers, key schemes, themes, and the screen (the tui module), over the workspace module's files, settings, console, and link to the interpreter and server.

Enumeration Type Documentation

◆ editMode

enum class tui::editMode : std::uint8_t
strong

Editor modes.

Only the vim scheme leaves insert. In insert, printable keys insert text; normal takes vim commands; visual extends a selection.

Function Documentation

◆ keyNameFromInput()

std::string tui::keyNameFromInput ( std::string_view input)

Returns the key name for one terminal input event, such as "C-x" for byte 0x18, "S-<left>" for ESC [ 1 ; 2 D, or "é" for a printable character.

Returns an empty string for input that is not a key (mouse reports, terminal replies, unknown sequences).
