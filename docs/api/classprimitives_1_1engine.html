Detailed Description

Runs plans.

Control-thread methods and audio-thread methods are marked; they may run concurrently with each other. Offline renders call both from one thread.

quantization quant )

Control thread: swaps to next after fade seconds of crossfade, at the position given by quant.

Replaces a swap that is still waiting for its quantization target. A negative or non-finite fade is 0; a fade longer than maxFade is maxFade. Plan IDs need not be unique: the engine tells swaps apart by call.
