Detailed Description

template<typename T, int Zeros, int Resolution>
class primitives::kaiserSinc< T, Zeros, Resolution >

A Kaiser-windowed sinc of Zeros zero crossings either side of its centre, as a table of Resolution points a crossing of T values, read by linear interpolation between points.

Point i holds sinc(u) × I0(β √(1 − (u / Zeros)²)) / I0(β) at u = i / Resolution crossings, computed in double, and a 0 follows the last point. Made where allocation is allowed; read on any thread.
