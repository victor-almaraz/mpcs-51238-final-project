1/// @file
2/// Compiles a source file to a validated graph (`interpreter.md` §2):
3/// read, evaluate, lower mappers, assign node IDs, sort, and validate.
4///
5/// The supported language is a subset of `grammar.md`: the special forms
6/// `define`, `defpiece`, `let` (bindings are sequential), `fn`, `do`,
7/// `if`, `cond`, `set!`, `quote`, `module`, `import`, and `pipe`; the
8/// object system (`defclass`, `defgeneric`, `defmethod`, `make`); the
9/// builtins `+ - * /` with dimensions, `= < > <= >=`, `not`, `list`,
10/// `map`, `range`, `tempo`, `mapper`, `slot-value`, and the mapper
11/// operations; and calls to every primitive in the `metadata` tables,
12/// named in kebab-case. Beat values for time parameters and in mappers
13/// are not supported yet.

41/// Settings for one compilation.
42struct compileOptions {
43 /// Name of the piece to build (`interpreter.md` §11.1).
44 std::string entry = "main";
45 /// Project seed, copied into the graph (`interpreter.md` §13.7).

47 /// The project's page port (`io.md` §12.2), copied into the graph;
48 /// `:port :page` stands for it.
49 std::optional<int> pagePort;
50 /// The project's name, `:name`, written as the label of its page's
51 /// root, which the drawn page names itself by.
52 std::string project;
53 /// Sample rate for `smp` literals, from the server's `/hello.ok`.
54 double sampleRate = 48000.0;
55 /// Most evaluation steps (forms evaluated) before the compilation
56 /// fails, so a program that does not end fails instead of hanging.
57 std::uint64_t maxSteps = defaultMaxSteps;
58 /// Reads the project file at a path relative to the project root, for
59 /// `import` (`interpreter.md` §11.2). When empty, importing a project
60 /// file is an error.
61 std::function<loadedFile(const std::string& path)> load;
62
63 /// Default for `maxSteps`. A piece of 64 voices takes about 2,300
64 /// steps; a Debug build evaluates about 200,000 steps a second.
65 static constexpr std::uint64_t defaultMaxSteps = 5'000'000;
66};

68/// Most nested evaluations (forms within forms, calls within calls, and
69/// mappers of mappers) before a compilation fails with an error. Each
70/// level uses C++ stack: about 1.3 KB at most in a Debug build, so the

97/// Result of a compilation.
98struct compileResult {
