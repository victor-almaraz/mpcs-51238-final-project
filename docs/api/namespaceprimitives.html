◆ sampleLoader

using primitives::sampleLoader
Initial value:
std::function<std::shared_ptr<const decodedAudio>(
std::string_view path, double sampleRate, std::string& error)>

Decodes the audio file at path and resamples it to sampleRate.

Returns null, with error set, when it cannot. Runs on the builder thread (primitives does no file I/O). The result is shared, so a loader may cache it.

Writes the MIDI bytes of e into out.

Returns the byte count, or 0 when e is not a MIDI event. The channel is masked to 4 bits and the data bytes to 7, so the bytes are always one valid message.
