Detailed Description

Owns all pipes (§6.2).

Control and event pipes are allocated at construction; each audio and video pipe when a plan that uses it is built (make()), on the control thread, so neither the audio thread nor the render thread allocates, and an engine holds only the audio pipes and frames its plans have used.
