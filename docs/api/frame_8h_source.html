49/// Frame pixels: premultiplied alpha, 32 bits per pixel as `0xAARRGGBB`
50/// (BGRA in memory on little-endian hosts), rows top to bottom with no
51/// padding. A frame also carries the transform that drawing applies
52/// (§7.7.2) and a drawing context bound to its pixels. Storage and the
53/// context are allocated at construction; nothing allocates afterwards.
54class frame {
