Detailed Description

Compiles a source file to a validated graph (interpreter.md §2): read, evaluate, lower mappers, assign node IDs, sort, and validate.

The supported language is a subset of grammar.md: the special forms define, defpiece, let (bindings are sequential), fn, do, if, cond, set!, quote, module, import, and pipe; the object system (defclass, defgeneric, defmethod, make); the builtins + - * / with dimensions, = < > <= >=, not, list, map, range, tempo, mapper, slot-value, and the mapper operations; and calls to every primitive in the metadata tables, named in kebab-case. Beat values for time parameters and in mappers are not supported yet.
