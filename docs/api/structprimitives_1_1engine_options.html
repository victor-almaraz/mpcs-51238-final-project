◆ minimumTaskCost

double primitives::engineOptions::minimumTaskCost = defaultMinimumTaskCost

The least estimated cost of a task, in nanoseconds a block, not negative (threads.md §5.2): the builder joins chains of nodes that cannot reach each other into one task until it holds this much.

At 0 every chain is a task of its own, the finest partition, which tests use so that independent nodes run on different threads. The output is the same at every value.

◆ shuffleSeed

std::optional<std::uint64_t> primitives::engineOptions::shuffleSeed = std::nullopt

For testing that the dependencies capture every conflict (threads.md §5.5, §9.1): when set, a block whose nodes one thread runs alone (one thread, or a schedule that is not parallel or does not fit the pool) runs them in a random order that keeps every dependency, drawn from this seed alone once for each plan and each crossfade, instead of plan order.

The output is then the same as in plan order; a node that touches shared state it does not declare renders differently.

◆ threads

int primitives::engineOptions::threads = 1

The threads that run a block, the audio thread included (threads.md §7): 1 runs every node on the audio thread in plan order; more add workers that run the plan's tasks beside it.

The output is the same at every count.

◆ workerStart

std::function<void()> primitives::engineOptions::workerStart = nullptr

Called first on each worker's own thread, to raise its priority, for example; may be empty.

It runs inside a noexcept function, so it must not throw: a throw ends the process. It may still be running when the engine's constructor returns, and the engine's destructor waits for it to return. It must own what it captures, since the engine's copy can outlive the objects in the caller's scope.
