Detailed Description

The marker for functions that run on the audio thread and the workers (AGENTS.md, real-time rules).

Clang's function-effect analysis (-Wfunction-effects) checks a marked function statically, and RealtimeSanitizer (-fsanitize=realtime) aborts when one allocates, frees, locks, or makes a system call at run time; realtimeSanitizerOff exempts one listed call from the sanitizer. realtimeAtomic checks at compile time that an atomic type takes no lock.

Every primitive includes this header, so it also rejects the builds in which nodes would not compute IEEE single precision step by step, as bit-identical renders need (threads.md §1.3, §4.2.1): -ffast-math, and float expressions evaluated in a wider type (x87 arithmetic). Contraction into fused multiply-adds is turned off by the build (-ffp-contract=off, cmake/EspressoHelpers.cmake).

Macro Definition Documentation

◆ ESPRESSO_ASSUME_NONBLOCKING_BEGIN

#define ESPRESSO_ASSUME_NONBLOCKING_BEGIN

Brackets code in a nonblocking function that Clang's analysis cannot show to be nonblocking but an invariant does: the destructor of a smart pointer that is empty by then, a queue slot the other end emptied, a library call whose storage was reserved beforehand.

Each use states its invariant in a comment; RealtimeSanitizer still checks the code at run time. Expands to a diagnostic push that ignores -Wfunction-effects where the compiler has that warning, and to nothing elsewhere.

A macro, like ESPRESSO_NONBLOCKING, because only _Pragma can scope a diagnostic. See the modern-cpp skill's section 9.

◆ ESPRESSO_NONBLOCKING

#define ESPRESSO_NONBLOCKING

Marks a function as nonblocking: void f() noexcept ESPRESSO_NONBLOCKING;, before override or final and before the function body.

Expands to [[clang::nonblocking]] where the compiler knows the attribute, and to nothing elsewhere.

A macro departs from the modern-cpp rules (no macros for code): an attribute cannot be aliased, and compilers without this one (Apple clang 15, GCC) reject it under -Werror as an unknown attribute. See the skill's section 9.
