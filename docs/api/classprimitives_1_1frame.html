Detailed Description

Frame pixels: premultiplied alpha, 32 bits per pixel as 0xAARRGGBB (BGRA in memory on little-endian hosts), rows top to bottom with no padding.

A frame also carries the transform that drawing applies (§7.7.2) and a drawing context bound to its pixels. Storage and the context are allocated at construction; nothing allocates afterwards.
