Lexes source in strict mode, for compilation.

◆ lexTolerant()

std::vector< token > interpreter::lexTolerant ( std::string_view source)

Lexes source in tolerant mode, for editor highlighting.

Never fails: malformed input becomes tokens of kind tokenKind::error, and lexing continues after them. Whitespace produces no tokens.

Variable Documentation

◆ maxEvalDepth

constexpr std::size_t interpreter::maxEvalDepth = 2000
inlineconstexpr

Most nested evaluations (forms within forms, calls within calls, and mappers of mappers) before a compilation fails with an error.

Each level uses C++ stack: about 1.3 KB at most in a Debug build, so the limit needs about 2.6 MB of a thread's stack.
