Detailed Description

The levels that reads finding one edge rule past a buffer's ends read (samples.md §6.6).

A buffer has one set of levels, made with the rule of the first reader that needed them. The two rules' levels differ only near each level's ends, within the reach of the kernel that makes them, so reads with the other rule take those frames from ends, made with their rule, and the rest from lines.
