◆ listProject()

static std::vector< std::filesystem::path > workspace::fileStore::listProject ( const std::filesystem::path & root,
std::size_t limit = std::numeric_limits< std::size_t >::max() )
static

Lists regular files under root, sorted, relative to it.

Hidden entries (names starting with .) and build directories are skipped. Symbolic links are listed by their own names, and linked directories are descended into, except a link to a directory that contains it, which would repeat forever. At most limit files are listed: the walk stops at the next one, so a caller that gets limit + 1 knows the folder holds more.

◆ modified()

static std::optional< std::string > workspace::fileStore::modified ( const std::filesystem::path & path)
static

When path was last written, as an opaque token that changes when the file does (its modification time, in the file clock's ticks); nothing when it cannot be read.

An editor keeps the token it read and writes only while the file still has it (patterns.md §13).

const std::string & text )
static

Writes text to a temporary file in the target's directory, flushes it, and renames it over path.

When path is a symbolic link, the file it names is replaced and the link is kept. On failure the original file is unchanged and the returned message describes the error (tui.md §7.2).
