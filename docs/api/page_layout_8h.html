Detailed Description

A page's layout computed in units (canvas.md §2): each control's footprint, each section's and pedal's placement of what it holds, and the size each group needs.

The interpreter lays a piece's page out with it, so the IR carries every size and place; the validator checks a layout with it; the renderer draws what it computed.
