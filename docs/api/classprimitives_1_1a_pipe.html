Detailed Description

Audio pipe: channels × block samples.

Writers sum; the engine zeroes the pipe at each block start (§5.2).

Constructor & Destructor Documentation

int capacity = metadata::maxChannels,
bool feedback = true )
explicit

Preallocates capacity channels (1 to maxChannels) of blockSize samples, twice when feedback is true (the second buffer serves feedback).

A pipe table's pipes take any shape a plan declares; a plan's private pipe (threads.md §4.2) has its pipe's channels and no feedback.

Sets the channel count, at most the capacity, and the feedback flag, which a pipe without a second buffer ignores.

A change of either clears both buffers, so no channel or feedback buffer replays old samples.
