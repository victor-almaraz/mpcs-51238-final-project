Detailed Description

Validates and answers client messages for one server (protocol.md §3–§6).

The session remembers each client that completed /hello. UDP gives no notice when a client goes away, and an idle editor sends nothing while it still receives notifications, so clients are not expired by time. Instead, a protocol::client sends /notify 0 when it is destroyed, and at most maxClients clients are kept: a /hello from a new client beyond that forgets the client heard from least recently.
