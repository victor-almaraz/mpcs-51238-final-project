Detailed Description

A page's layout drawn as HTML (dsl-ui.md §7.1): the document the page bridge serves when a project has no ui/index.html of its own.

Each element becomes the es-* element its kind names (metadata::pageKinds()), with its parameters as that element's attributes, and the document loads /espresso.js and /espresso-ui.js.
