1/// @file
2/// Compiles a source file to a validated graph (`interpreter.md` §2):
3/// read, evaluate, lower mappers, assign node IDs, sort, and validate.
4///
5/// The supported language is a subset of `grammar.md`: the special forms
6/// `define`, `defpiece`, `let` (bindings are sequential), `fn`, `do`,
7/// `if`, `cond`, `set!`, `quote`, `module`, `import`, and `pipe`; the
8/// object system (`defclass`, `defgeneric`, `defmethod`, `make`); the
9/// builtins `+ - * /` with dimensions, `= < > <= >=`, `not`, `list`,
10/// `map`, `range`, `tempo`, `mapper`, `slot-value`, and the mapper
11/// operations; and calls to every primitive in the `metadata` tables,
12/// named in kebab-case. Beat values for time parameters and in mappers
13/// are not supported yet.

40/// Settings for one compilation.
41struct compileOptions {
42 /// Name of the piece to build (`interpreter.md` §11.1).
43 std::string entry = "main";
44 /// Project seed, copied into the graph (`interpreter.md` §13.7).

46 /// Sample rate for `smp` literals, from the server's `/hello.ok`.
47 double sampleRate = 48000.0;
48 /// Most evaluation steps (forms evaluated) before the compilation
49 /// fails, so a program that does not end fails instead of hanging.
50 std::uint64_t maxSteps = defaultMaxSteps;
51 /// Reads the project file at a path relative to the project root, for
52 /// `import` (`interpreter.md` §11.2). When empty, importing a project
53 /// file is an error.
54 std::function<loadedFile(const std::string& path)> load;
55
56 /// Default for `maxSteps`. A piece of 64 voices takes about 2,300
57 /// steps; a Debug build evaluates about 200,000 steps a second.
58 static constexpr std::uint64_t defaultMaxSteps = 5'000'000;
59};

61/// Most nested evaluations (forms within forms, calls within calls, and
