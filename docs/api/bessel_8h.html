 I0(x), the modified Bessel function of the first kind of order 0, by its power series: the sum of (x / 2)^2k / (k!)^2 from k = 0, adding terms while the last one added exceeds tolerance times the sum, and at most 63 terms past the first.
 

Detailed Description

The modified Bessel function of the first kind of order 0, which shapes the Kaiser windows of the band-limiting kernels: the reads and writes of buffers (samples.md §6.5) and the server's resampler (§4.5.1).
