◆ lexStrict()

lexResult interpreter::lexStrict ( std::string_view source)

Lexes source in strict mode, for compilation. Stops at the first malformed token and reports it in lexResult::failure.

◆ lexTolerant()

std::vector< token > interpreter::lexTolerant ( std::string_view source)

Lexes source in tolerant mode, for editor highlighting. Never fails: malformed input becomes tokens of kind tokenKind::error, and lexing continues after them. Whitespace produces no tokens.
