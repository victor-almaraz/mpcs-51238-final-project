Detailed Description

A client endpoint. request() blocks and may be called from one thread at a time; a receiver thread routes replies and passes unsolicited messages to the listener.

Transfers payload as plan planId: /ir.begin, chunks, and /ir.end, resending missing chunks (§6). After every chunksPerWindow chunks it waits for /synced, so a burst never overflows a small server receive buffer. Returns an error message on failure.
