Detailed Description

The terminal editor: buffers, key schemes, settings, the console, and the link to the interpreter and server (the tui module).

std::size_t offset )

Byte range [first, second) of the datum that ends at or before offset, including leading quotes.

This is the form evalLastForm evaluates. Returns nothing when no complete datum precedes offset.

◆ highlight()

highlightResult tui::highlight ( std::string_view source)

Highlights source with the tolerant lexer.

Data after a #; datum comment are highlighted as comments.

◆ keyNameFromInput()

std::string tui::keyNameFromInput ( std::string_view input)

Returns the key name for one terminal input event, such as "C-x" for byte 0x18, "S-<left>" for ESC [ 1 ; 2 D, or "é" for a printable character.

Returns an empty string for input that is not a key (mouse reports, terminal replies, unknown sequences).

◆ matchingDelimiter()

Byte offset of the delimiter matching the one at offset, using tokens from highlight().

Returns nothing when offset is not on a bracket or the bracket is unmatched (tui.md §6.5).
