# espresso

![tests](docs/badges/tests.svg)
![coverage](docs/badges/coverage.svg)

espresso is a Linux-first workstation for acousmatic, aleatory, and automatic music, and the Lisp dialect its pieces are written in. Pieces compile to an intermediate representation (IR), which a native C++ engine plays.

## Requirements

- CMake 3.25 or later, a C++20 compiler (GCC 12 or later, Clang 15 or later), and Git
- OpenSSL
- Linux: `pkg-config` and the ALSA and JACK development packages
- macOS: the Xcode Command Line Tools

[Installing](docs/guide/installing.md) lists the packages for each platform, and what the GUI editor needs besides.

## Build

```bash
cmake -B build -S . -G Ninja
cmake --build build
ctest --test-dir build --output-on-failure
```

The build produces `build/bin/espresso-server` and `build/bin/espresso-client`. CMake downloads every library into `third_party/` at configure time.

The API reference is regenerated after a change to a public header:

```bash
cmake --build build --target docs
```

Doxygen writes the HTML into `docs/api/`, without timestamps, so unchanged headers leave its files unchanged. `docs/api.md` is its main page.

`docs/reference/primitives.md` is written from the primitive tables in `src/metadata/primitiveSpec.cpp`, and the interpreter suite fails when it differs from them. After a change to the tables, the page is rewritten with:

```bash
cmake --build build --target primitive-reference
```

The manual is the documents of `docs/` and the C++ API as one HTML site, built by Sphinx with MyST-Parser and Breathe into `build/docs/html/`, which is not committed. The build fails on any warning. Sphinx and its extensions are not downloaded by CMake: install the versions `docs/requirements.txt` lists, for example in a virtual environment, and give CMake its `sphinx-build` when it is not on the `PATH`:

```bash
python3 -m venv build/docs-venv
build/docs-venv/bin/pip install -r docs/requirements.txt
cmake -B build -S . -DSPHINX_EXECUTABLE="$PWD/build/docs-venv/bin/sphinx-build"
cmake --build build --target manual
```

Without Doxygen or `sphinx-build`, the target reports that it is skipped. `docs/index.md` is the manual's contents, and `docs/conf.py` its configuration.
