Detailed Description

Reassembles IR announced by /ir.begin, one transfer per plan ID.

Used by the server's network thread. At most maxPendingTransfers transfers, announcing at most maxIrBytes in total, are kept: a new announcement abandons the oldest transfers until it fits, so transfers that a client never finishes cannot accumulate.
