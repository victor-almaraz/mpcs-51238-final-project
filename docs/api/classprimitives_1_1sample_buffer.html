Detailed Description

A block of audio memory of a fixed number of channels and frames, planar and zeroed when made (samples.md §2).

Allocated by the builder, written and read by the thread that runs each node that uses it, in the order the plan's dependencies give them, and freed with the last plan that holds it on the control thread.
