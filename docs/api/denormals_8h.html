Detailed Description

The floating-point mode of every thread that runs nodes (AGENTS.md, real-time rules; threads.md §6.6): round to nearest, exceptions masked, and flush-to-zero with denormals-are-zero.

Decaying filter and delay tails reach denormal values, which are slow on most CPUs; the mode treats them as zero. Every such thread sets the whole control word, so none inherits a rounding mode or a trap from the thread that made it, and every thread computes the same bits.
