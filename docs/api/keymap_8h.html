Detailed Description

Key binding schemes as data, and the state machine that resolves key sequences to command names (tui.md §8.1–8.5). Has no terminal dependency.

Keys use Emacs notation: C-x (Control), M-f (Meta), S-<left> (Shift), C-M-_, named keys such as RET, TAB, DEL (backspace), ESC, SPC, <delete>, <up>, <home>, <prior> (Page Up), <next> (Page Down), <f5>, and printable characters as themselves. A sequence is keys separated by spaces: C-x C-s.
