1/// @file
2/// The marker for functions that run on the audio thread and the workers
3/// (AGENTS.md, real-time rules). Clang's function-effect analysis (-Wfunction-effects)
4/// checks a marked function statically, and RealtimeSanitizer
5/// (-fsanitize=realtime) aborts when one allocates, frees, locks, or makes
6/// a system call at run time; realtimeSanitizerOff exempts one listed
7/// call from the sanitizer. realtimeAtomic checks at compile time that an
8/// atomic type takes no lock.

47/// Brackets code in a nonblocking function that Clang's analysis cannot
48/// show to be nonblocking but an invariant does: the destructor of a smart
49/// pointer that is empty by then, a queue slot the other end emptied, a
50/// library call whose storage was reserved beforehand. Each use states
51/// its invariant in a comment; RealtimeSanitizer still checks the code at
52/// run time. Expands to a diagnostic push that ignores -Wfunction-effects
53/// where the compiler has that warning, and to nothing elsewhere.
54///
55/// A macro, like ESPRESSO_NONBLOCKING, because only `_Pragma` can scope a
56/// diagnostic. See the modern-cpp skill's section 9.
57#if defined(__has_warning)
58#if __has_warning("-Wfunction-effects")
59#define ESPRESSO_ASSUME_NONBLOCKING_BEGIN \
60 _Pragma("clang diagnostic push") _Pragma("clang diagnostic ignored \"-Wfunction-effects\"")

62#define ESPRESSO_ASSUME_NONBLOCKING_END _Pragma("clang diagnostic pop")
63#endif
64#endif

81/// A type whose atomics the audio thread and the workers may use:
82/// `std::atomic<T>` is lock-free on every processor the build targets
83/// (`std::atomic<T>::is_always_lock_free`). On a target without the
84/// instructions for the type's width, such as `std::atomic<double>` on a
85/// 32-bit ARM core without `LDREXD`, every operation calls the library,
86/// which takes a lock from a table of its own, against the real-time
87/// rules (AGENTS.md). Each class that holds an atomic used on those
88/// threads asserts its types beside it: `static_assert(realtimeAtomic<float>);`.
89template <typename T>
90concept realtimeAtomic = std::atomic<T>::is_always_lock_free;

92/// The alignment, in bytes, of data that one thread writes and others
93/// read or write on the audio thread's path: a queue's positions, the
94/// worker pool's counters, each thread's busy time. 128 bytes keeps two
95/// such members off one unit of coherence on the processors the engine
96/// targets: on x86-64, Intel's L2 spatial prefetcher fetches 64-byte lines
97/// in aligned pairs, so members 64 bytes apart still move between cores
98/// together; Apple's M-series cores and some other ARM cores have 128-byte
99/// lines. `std::hardware_destructive_interference_size` is not used: its
100/// value may change with the compiler's tuning flags, which would change
101/// the layout of classes in headers between translation units.
102inline constexpr std::size_t cacheLine = 128;
