◆ operands

enum class metadata::operands : std::uint8_t
strong

How a mapper operation (primitives.md §7.9) treats the dimensions of its operands: the input, then the parameters in table order.

Enumerator
none 

Not a mapper operation.

plain 

Every operand is a plain number: exp, log, sin, cos, tanh, pow.

keep 

The result has the input's dimension: floor, round.

sign 

As keep, but a level is ambiguous: neg, abs.

same 

Every operand has the input's dimension, as the result does: min, max, clamp, quantize.

ranges 

The input shares a dimension with the first two parameters; the last two share the result's: scale, scaleExp.

enum class metadata::rule : std::uint8_t

What a constraint requires of a node (constraint).

Enumerator
anyInput 

At least one of the input ports ports is bound.

anyOutput 

At least one of the output ports ports is bound.

entryPerPipe 

List parameter param, when it has entries, has one per pipe of input ports[0]

notEmpty 

List parameter param has an entry; an absent list is empty.

channels 

Output ports[0], when bound, has a pipe of at least count channels.

audioWith 

When input ports[0] is bound, output ports[1] is an audio pipe.

textWith 

When input ports[0] is bound, text or text list parameter param is not empty.

powerOfTwo 

Numeric parameter param, given or by default, is a power of two.

oneOf 

Numeric parameter param, given or by default, is one of values

scheme 

Text parameter param, when not empty, starts with one of names

atMost 

Text list parameter param has at most count entries.

headers 

Each entry of text list parameter param is a request header, Name: value

entryPerChannel 

Text list parameter param, when it has entries, has one per channel of port ports[0], an input or an output, when it is bound.
