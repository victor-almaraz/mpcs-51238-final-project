Detailed Description

A queue between one primitive and the I/O layer.

Shared by the primitive and its plan; the hub keeps only a weak reference, so a port is gone when its plan is. Input ports accept data only while active, so a plan that is loaded but not yet playing does not accumulate stale messages. An input port names the node that reads it: the hub delivers each message to one active port per node, so an adopting node and the node it replaces, both active during a swap, never receive it twice.
