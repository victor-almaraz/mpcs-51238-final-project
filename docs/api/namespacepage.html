std::string page::render ( const metadata::pageNode & layout,
bool served = true )

The document that draws layout, a tree whose root is a page; the same layout gives the same text.

Parameters its kind does not have are left out. A served page, the one the server serves, loads itself again when the server sends reloadAddress, its value controls keeping the values the player set; a page written into a project (--page, Save Page), which the layout no longer draws, does not.
