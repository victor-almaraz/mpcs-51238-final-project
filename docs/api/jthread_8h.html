Detailed Description

espresso::jthread: a thread that asks itself to stop and joins when it is destroyed, with the interface of C++20's std::jthread that the project uses.

Unlike std::jthread, every thread gets a stack of threadStackBytes: secondary-thread stacks otherwise differ by platform (512 KiB on macOS; RLIMIT_STACK, or 2 MiB when unlimited, with glibc), and the interpreter's worker needs a measured size (interpreter::maxEvalDepth). Header-only, so a module that includes it, such as primitives, needs no link to protocol.
