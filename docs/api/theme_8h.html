Detailed Description

Editor themes.

Every theme assigns a color to the same set of roles, so views ask for a role ("secondary text", "surface", "accent") and never for a literal color. Truecolor themes fall back to 256 or 16 colors on terminals without truecolor support (tui.md §6.6).
