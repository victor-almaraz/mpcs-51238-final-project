Detailed Description

Events carried by event pipes (primitives.md §5.4): MIDI messages, triggers, values, and OSC messages, with MIDI byte conversion and non-allocating OSC helpers.

Writes the MIDI bytes of e into out. Returns the byte count, or 0 when e is not a MIDI event. The channel is masked to 4 bits and the data bytes to 7, so the bytes are always one valid message.
