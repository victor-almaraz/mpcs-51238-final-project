Detailed Description

A single-producer, single-consumer queue of OSC packets that keeps of each only its time, its size, and the bytes it uses, one after another in a ring (primitives.md §7.3.5).

A message of a few dozen bytes takes a few dozen, where a slot of oscPacket takes over 1 KB: a piece of hundreds of OSC inputs, each with its own port, holds megabytes of queues rather than a hundred. The ring is written at construction, so neither end takes a page fault on its first use.
